**Проблема:** публичное портфолио должно быть не только визуально готовым, но и достаточно надежным, чтобы отправлять его работодателям и техническим контактам.

**Действие:** собрал статическое bilingual-портфолио с Markdown-контентом, генерацией PDF CV, проверкой production-конфига, link checks, Playwright smoke tests, Lighthouse gates и деплоем на GitHub Pages.

**Результат:** каждый production deploy проходит автоматические проверки и публикуется на GitHub Pages с custom domain без затрат на хостинг.
