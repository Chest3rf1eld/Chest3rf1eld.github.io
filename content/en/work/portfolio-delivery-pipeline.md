**Problem:** a public portfolio should be reliable enough to share professionally, not just visually finished.

**Action:** built a static bilingual portfolio with Markdown content, generated CV PDFs, production config validation, link checks, Playwright smoke tests, Lighthouse gates, and GitHub Pages deployment.

**Result:** every production deploy is gated by automated checks and published on GitHub Pages with a custom domain at zero hosting cost.
